# PYNQ-Z2供应商板定义

本目录保留既有Vivado 2026.1环境中的TUL PYNQ-Z2 board.xml、preset.xml、part0_pins.xml和板卡图片。
board vendor=tul.com.tw、file_version=1.0、part=xc7z020clg400-1，与原构建使用的board_part一致。
这些是供应商/工具配套原件，不声明为本队原创，相关权利归原权利人。
提交专用FFT/M4入口在创建新工程前设置board.repoPaths指向本目录，不修改用户的全局Vivado配置。
本轮只复制和核对原件，没有启动Vivado或验证新环境的board catalog加载。
