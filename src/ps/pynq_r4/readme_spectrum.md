# PYNQ-Z2 频谱分析仪 R4 集成版

版本：`spectrum_software_1_r4_bplus`

日期：2026-11-02

R4 在 R3 的 PL FFT、DMA、codec 和 Web 实时频谱基础上，加入：

- 同一端口 `/` 的“当前频谱 / 深入分析 / 我的记录 / 演示样例 / 频率响应”入口；
- 历史实验回放、平均/保持、A/B 游标、趋势和同进程状态订阅；
- 实测 RC 幅相报告入口；
- 实时频谱与频率响应两套 Overlay 的互斥模式切换；
- 所有命令共用 R3 `X-Spectrum-Token` 鉴权。

## 启动

将完整 board ZIP 上传到 Jupyter 根目录后：

```bash
cd /home/xilinx/jupyter_notebooks
python3 -m zipfile -e spectrum_software_v1_r4_bplus_board.zip .
cd spectrum_software_v1_r4_bplus
python3 spectrum_service.py stop --port 8091
python3 spectrum_app.py --mode live --bind 0.0.0.0 --port 8091
```

浏览器打开：

```text
http://板卡IP:8091/
```

只允许一个 R4 服务占用 8091。不要额外启动 B 的 8092 服务。

## 页面

### 实时频谱

保留 R3 的 PL FFT、LIVE/REPLAY、瀑布、留样、截图和会话导出。

### 实时频谱

- 当前频谱、瀑布、采集控制、留屏和会话导出。

### 深入分析

- 只读取当前实时采集的状态、帧数、缺口、平均/保持累计和当前主峰；
- 用户可将当前分析结果主动保存到“我的记录”；
- 内置演示数据不会进入此页面。

### 我的记录

- 只列出用户主动保存的实时分析和频率响应记录；
- 记录带创建时间、来源、类型和 SHA256；
- 没有用户记录时显示空状态；
- 支持查看和删除。
- 分析记录使用同一套多帧播放器；频率响应记录直接显示幅相图和逐点表。
- 用户频率响应记录可下载逐点 CSV 或包含完整条件、拟合和频点数据的 JSON。

用户记录保存在软件目录外：

```text
../user_data/records/
```

升级或替换 R4 软件目录时，用户记录不会被覆盖。

分析记录包包含：

```text
record.json
sample_index.json
metric_timeline.jsonl
frames/*_words.npy
frames/*_state.json
frames/*_render.json
manifest.json
```

每条分析记录最多保存 32 份完整频谱和 5000 条指标；超过完整谱上限时
采用环形替换并记录溢出数量。

### 演示样例

同源 iframe 加载 `/bx/`，使用：

```text
/bx/api/replay/index
/bx/api/replay/frame
/bx/api/replay/trend
/bx/api/export
```

- 内置数据只用于展示，不归入用户记录；
- 只有用户主动选择演示记录后才加载数据；
- 清空选择后返回未加载状态。

### 频率响应

提供：

- 停止实时频谱并进入电路测量；
- codec 配置和 fs 测量；
- 双声道计数器自检；
- 双声道采集；
- 安全退出电路测量并恢复实时频谱；
- 同进程状态订阅及报告导出；
- RC 幅频图像、CSV、JSON 和说明入口。
- 用户可将当前双声道采集摘要保存到“我的记录”。

频率响应测量分为两个明确类型：

```text
RC 低通滤波器
通用系统
```

RC 低通滤波器记录要求：

- 先进入电路测量模式并完成接口配置；
- 设置实际 R、C、温度和信源说明；
- 逐点输入目标频率并采集；
- 每个频点保存原始左右声道块、C0 校准、拟合结果和质量状态；
- 至少 3 个频点才能保存曲线；
- 16 个设计频点全部完成时标记为完整频率响应记录。

通用系统记录要求：

- 填写被测系统名称，型号、编号和接口说明可选；
- 记录信号源、温度和测量范围；
- 逐点保存输入参考和被测系统输出的原始双声道块；
- 只计算实测复数传递比、增益和相位；
- 不要求 R/C，不自动生成 RC 理论曲线或截止频率；
- 至少 3 个用户指定频点后可以保存。

通用系统仍需对每个 1024 点同步块做**正弦相量估计**，以求出左右声道的
幅度和相位；这不是 RC 曲线拟合。只有 RC 模式才会执行一阶传递函数拟合。
`POOR_FIT_OR_SYNC_UNVERIFIED` 表示输入不是稳定的同频正弦、目标频率与实际
发生器不一致，或信号存在明显失真。

## 硬件模式

两套实验使用不同 Overlay，禁止同时运行。

模式顺序：

```text
实时频谱
  -> 停止运行
  -> 关闭 FFT runtime
  -> 释放 FFT Overlay/DMA
电路测量
  -> 停止采集 DMA
  -> 关闭测量 Overlay
实时频谱
  -> 重建 SpectrumRuntime
```

任何 DMA 停止失败、活动缓冲未释放或 unsafe 状态都会阻止模式切换。
需要重启板卡时不得强制继续加载另一套 bitstream。

## 已知边界

- 实时频谱与频率响应都是单帧快照，帧间允许空隙。
- 历史回放使用归档结果，不重新执行 FFT。
- 频率响应使用时域双声道测量，不把左右声道解释成 FFT 实部/虚部。
- 同进程状态订阅代码已完成，仍需实板短测。
