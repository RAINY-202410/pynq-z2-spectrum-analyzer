# 设计与验证材料

- design_report.docx：已补实物、五个功能界面、用户记录和ROSS协作截图的24页正式设计报告；第15.1节为三步快速启动。
- design_report.md：从同版Word提取的文字版；图件和排版以Word为准。
- ai_collaboration.md及ai_records/：原始提示词、AI回复、工具日志、失败纠正与来源回执。
- verification_report.md：版本化功能与实测证据，不混用主机验证和板端验收。
- implementation_report.md：冻结硬件对应的资源/时序与构建记录。
- required_validation.md：提交布局的独立构建验证状态与范围。
- final_recheck.md、submission_checklist.md、package_review.md：交付完整性及材料对应索引。
- known_gaps.md：CMA、绝对电压、外部I/O与完整r4交互等证据边界。

原始协作摘录为真实公开会话条目，不将提示词模板归纳成逐字对话；选定摘录不等于完整开发历史。
